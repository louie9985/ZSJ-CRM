# 组织模块

- 模块位置：`packages/crm-modules/organization`
- 类型：CRM 项目核心模块
- 状态：当前实现
- 架构依据：ADR-0008、ADR-0034

## 职责

组织模块独占 Workforce Person、实名 Profile、Employment、Organization Unit、Position 和有效期 Assignment。它提供当前或指定时间点的人员组织上下文，并通过关闭旧事实、创建新事实表达调岗、兼岗和离职，不覆盖历史。

`resolveWorkforcePersonContext(workforcePersonId, at, assignmentId?)` 以稳定人员 ID 解析上下文。多个有效 Assignment 保持分离；调用者可以显式选择一个有效 Assignment，模块不得自动取第一条或合并权限。

## 非职责

- 不保存账号、登录标识、密码、Cookie、Session 或角色 Grant。
- 不维护额外认证主体关联；账号由 `workforce-access` 直接唯一关联人员。
- 不作出最终授权决定，不查询其他模块表，不暴露 Prisma 类型或 transaction client。
- 不在当前阶段实现外部目录同步、外部用户、邀请或第三方身份映射。

## 失败关闭

人员不存在、没有有效 Employment、选择的 Assignment 无效、组织层级循环或有效期事实冲突时返回稳定错误。关闭一个 Assignment 只撤销该上下文，不等同于离职；关闭 Employment 才表示工作关系结束，并使内部访问失败关闭。
