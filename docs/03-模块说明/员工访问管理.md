# 员工访问管理

- 模块位置：`packages/crm-modules/workforce-access`
- 状态：当前实现
- 架构依据：ADR-0034

## 所有权

模块独占内部 Account、唯一 `workforcePersonId` 关联、规范化用户名/手机号历史、Argon2id Password Credential、乐观 revision 和单调递增 `securityRevision`。账号状态只有 `active | disabled`。

用户名不区分大小写且永久占用。手机号去除空格和连字符后比较；旧值默认继续占用，只有显式授权和审计的释放命令才可复用。

密码为 8–64 位可打印半角 ASCII。持久化只保存固定 Argon2id 参数生成的 hash；明文和派生值不得进入公开契约、操作收据、日志、审计、Trace、错误、响应或后台消息。

## 边界

模块不拥有 Person/Employment/Assignment、角色 Grant、浏览器 Session 或最终授权。API 的 `AccountAccessApplicationService` 通过公开端口组合这些能力，任何模块不得跨表查询。

密码重置在短事务中替换 Credential 并递增 `securityRevision`。所有受保护 Session 读取都核对 revision，因此 Redis 清理失败也不会保留旧访问。

创建账号的密码 hash 在数据库事务外计算；Person、Employment、Assignment、Profile、Account、Credential、基础角色和审计在应用服务控制的一个短事务内原子提交。成功幂等重放不再次处理密码，失败重试使用新的 `Idempotency-Key`。
