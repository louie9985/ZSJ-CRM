# ADR-0035：CRM 单项目 Web 应用结构

- 状态：已接受
- 日期：2026-08-05
- 适用范围：CRM Web、员工移动入口、兼职入口、部署与文档
- 取代：ADR-0003、ADR-0015、ADR-0016、ADR-0019 中关于多应用目录、外部客户端和独立移动制品的部分决定

## 决策

1. 当前系统只有一个 CRM 项目和一个 Web 制品 `apps/workbench-web`。登录成功直接进入 `/crm/workspace`，不存在应用选择页、应用目录或切换应用。
2. 员工 PC 使用 `/crm/*`，员工移动页面使用同一制品的 `/mobile/*`；两者共用员工 `pc` Session、账号、权限和审计边界。
3. 兼职人员使用同一 Web 制品的 `/part-time/*` 入口，但由 `part_time_access` 独立账号、凭证、Session、限流和审计模块保护。兼职身份不自动关联员工身份。
4. CRM 核心能力位于 `packages/crm-modules`，SDK 位于 `packages/crm-sdk`。不存在 `app-registry`，服务端只过滤 CRM 固定导航和当前授权。
5. 当前不构建外部门户、微信小程序、邀请身份或非浏览器客户端。任何新增入口必须先拥有明确业务场景、数据边界、契约和 ADR。

## 影响

历史多客户端和应用注册 ADR 仅作为被取代记录保留，不得从其文本恢复运行时路由、依赖、部署服务或权限模型。数据库历史迁移不可变，CRM 命名与兼职结构通过新增迁移完成。
