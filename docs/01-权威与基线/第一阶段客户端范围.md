# 第一阶段客户端范围

- 状态：已批准
- 日期：2026-08-04
- 架构依据：ADR-0034

## 单一 Web 应用入口

- `apps/workbench-web`：唯一 CRM Web 制品。PC 使用 `/crm/*`，员工移动页面使用 `/mobile/*`，兼职入口使用 `/part-time/*`。
- 员工 PC 与员工移动页面共用员工 `pc` Session；兼职使用独立 `part-time` Session 和账号表。

三类入口复用同一 HTTP 契约结构，但员工与兼职 Cookie、账号、限流和审计边界保持隔离。服务端授权和领域校验不能由隐藏菜单、路由守卫或端内校验替代。

## 当前边界

第一阶段没有外部端、微信小程序、原生 iOS/Android App 或非浏览器客户端。不得恢复已删除的外部应用、外部 OpenAPI、邀请模型或小程序会话句柄，除非新的业务场景、数据边界和 ADR 已获确认。

当前 Web 制品使用 Vite + React；移动页面采用响应式 CRM 壳层。历史 Taro 工程仅保留为迁移测试材料，不作为独立部署入口。
