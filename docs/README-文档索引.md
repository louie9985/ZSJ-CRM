## 阅读路径建议

- **决策/汇报** → 项目立项书
- **产品评审** → PRD总册 → 各分册 PRD → 总纲第 4/5/6 章
- **开工前（人或 AI）** → 总纲第 0 章（宪法）→ 开发文档架构 → 开发手册细则 → 事件契约表
- **搭 AI 流水线** → AI多Agent协作机制 → 把 `AI-Agents配置/` 复制为仓库 `.claude/`

## 文档治理

总纲是规则与设计的唯一事实源；PRD/开发文档/事件契约表是其不同视角的展开，不复制规则正文只引编号，避免多处维护漂移。三份受控文档（总纲、开发手册细则、事件契约表）变更需版本递增 + changelog，一切规则/口径变更走 M11 需求工单。"五、组织与经营设计层"的 4 份文档属于参考性业务/组织设计稿，不属于受控文档，不适用上述变更流程；其内容与总纲或三份受控文档冲突时，以总纲/受控文档为准。

> **关于《技术选型-V3.3》**：技术选型定稿 ＋ 变更记录（CR-01~12），已经人工评审放行并回写总纲。CR-11（移动端由 App 改小程序/H5）见第 9 章，CR-12（PC Web UI 栈切换）见变更清单与 changelog。文档内 🟢=增补 / 🟡=推翻既定 / 🔴=推翻既定决策 / ✅=已决，保留作决策留痕。
